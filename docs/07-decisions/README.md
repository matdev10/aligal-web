# Architecture Decision Records

Esta carpeta contiene decisiones arquitectónicas relevantes del proyecto.

Formato recomendado:

```text
ADR-XXX-titulo.md
```

Cada ADR debe indicar:

- Estado
- Contexto
- Decisión
- Motivo
- Consecuencias

No modificar ADR aceptados para ocultar decisiones anteriores. Si una decisión cambia significativamente, crear un nuevo ADR que reemplace al anterior.
